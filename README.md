# 💡 TASKATY - منصتك الذكية لإدارة المهام والوقت

تطبيق **TASKATY** هو تطبيق متكامل ومصمم بذكاء لإدارة المهام اليومية، تنظيم الوقت، ومتابعة الإنتاجية بأعلى كفاءة.

## 🚀 مميزات التطبيق
- 📅 **دعم التقويم المزدوج:** الهجري والميلادي.
- ⏱️ **مؤقت بومودورو (Pomodoro):** لزيادة التركيز أثناء المذاكرة والعمل.
- 🎨 **تصنيف المهام والأولويات:** ألوان مخصصة لكل مستوى أهمية.
- 📊 **إحصائيات وبيانات تفاعلية:** متابعة أداء الإنجاز اليومي.
- 💾 **قاعدة بيانات سريعة وآمنة:** لحفظ المهام والملحوظات.

Developed with Python & Streamlit.
